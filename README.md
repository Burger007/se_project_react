# WTWR (What to Wear?)

## About the project

The idea of the application is pretty simple - we make a call to an API, which then responds with the daily weather forecast. We collect the weather data, process it, and then based on the forecast, we recommend suitable clothing to the user.

## Links

- - [Figma Design](https://www.figma.com/designbfVOvqlLmoKZ5lpro8WWBe/Sprint-14_-WTWR)

- [Backend repository](https://github.com/Burger007se_project_express)

- Sign up log in and log out with JWT authentication

- Protected profile page for users who are logged in

- Edit profile name and avatar

- Add and delete your clothing items

- Like and unlike clothing items

- Weather-based clothing recommendations with, °F / °C toggle

## Running the project locally

The frontend needs the backend API running at the same time

### 1. Backend (port 3001)

Make sure MongoDB is installed and running then

```bash

git clone https://github.com/Burger007/se_project_express.git

cd se_project_express

npm install

npm run dev
```
